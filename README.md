# 📊 Customer Churn Analysis Dashboard

## 📌 Project Overview
This project analyzes customer churn behavior to identify key factors contributing to customer attrition and provides actionable insights to improve retention.

## 🎯 Objective
To understand why customers leave and suggest data-driven strategies to reduce churn.

---

## 🛠️ Tools Used
- Excel (Data Cleaning & Preparation)
- Power BI (Dashboard & Visualization)

---

## 📊 Key Insights
- Month-to-month contract customers have the highest churn rate.
- New customers are more likely to leave early.
- Higher monthly charges are associated with increased churn risk.

---

## 💡 Business Recommendations
- Encourage long-term contracts through discounts or benefits.
- Improve onboarding experience for new customers.
- Target high-risk customers with personalized retention offers.
